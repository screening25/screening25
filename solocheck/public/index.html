혼자 일하는 사람이 쓰러지면, 누가 언제 알게 되나요

솔로체크는 단독작업자에게 정한 간격마다 안부 확인을 보냅니다.
응답이 없으면 관리자 휴대폰에 바로 알림이 갑니다.
확인, 무응답, 대응 시각은 고칠 수 없는 기록으로 남아 월간 보고서가 됩니다.

이렇게 동작합니다

1. 작업 시작
작업자가 받은 링크를 열고 장소와 간격(15~120분)을 고릅니다. 설치할 앱이 없습니다.

2. 안부 확인
정한 시간이 되면 휴대폰이 울립니다. 버튼 하나로 안부를 보냅니다.

3. 무응답 보고
5분 안에 응답이 없으면 관리자에게 알림이 갑니다. 긴급 호출은 즉시 갑니다.

4. 기록
모든 사건이 해시 사슬로 묶여 쌓입니다. 중간 기록을 고치거나 지우면 검증에서 드러납니다. 월별 CSV로 받습니다.

지금 할 수 있는 것과 없는 것

할 수 있는 것: 안부 확인, 무응답 알림, 긴급 호출, 관리자 대응 기록, 월간 보고서, 기록 위변조 검증.

아직 없는 것: 위치 추적, 쓰러짐 자동 감지, 문자·알림톡 발송.
알림은 웹 푸시로 갑니다. 안드로이드 크롬에서 가장 잘 동작하고, 아이폰은 홈 화면에 추가해야 받습니다.

파일럿

한 달 유료 파일럿으로 시작합니다.
작업자 10명까지, 30만 원(부가세 별도)입니다.
연간 계약으로 이어지면 파일럿 비용을 첫해 요금에서 뺍니다.

문의처를 불러오는 중입니다.
